# 수식 검토: 변환 뒤 수식을 눈으로 대조하고 고치는 HTML 페이지

- 날짜: 2026-10-24
- 상태: 결정
- 만든 스킬: decide-direction (사용자 요청을 구현하기 전 방식 선택)

## 질문
변환이 끝난 뒤 수식마다 "쪽·번호·PDF 크롭·문서에 들어간 LaTeX"를 나란히 보여 주고, 고친 LaTeX를 MD에 바로 반영하려면
(A) 정적 HTML 한 장 + 브라우저의 File System Access API로 제자리 저장, (B) 로컬 웹 서버를 띄워 저장 요청을 받기, (C) HTML은 보기만
하고 수정은 CLI 명령으로 적용 — 중 무엇으로 할 것인가.

## 제약
- 설치는 `main_gui.bat` 더블클릭 한 번이어야 하고 서버 프로세스·포트·방화벽 질문이 생기면 안 된다. 변환 결과(이미지·.md)는 커밋하지 않는다.
- 본문 텍스트는 건드리지 않는다: 수정은 그 수식의 `$$ … $$` 블록만 바꾼다(inlinemath 원칙과 같음).
- Word(.docx)의 수식은 OMML 개체라 파일을 다시 쓰기 어렵다. Word는 보기만 지원한다.
- `--math-mode latex`(새 기본값)에서는 검증된 수식의 이미지가 MD에 들어가지 않으므로, 대조용 크롭은 페이지가 따로 가져야 한다.

## 대안과 비교
| 대안 | 효과 | 설치 리스크 | 비용 | 되돌리기 |
|---|---|---|---|---|
| A. 정적 HTML + File System Access API(Edge·Chrome), 그 외 브라우저는 수정본 다운로드 | 파일 하나, 더블클릭으로 열림, 제자리 저장 | 없음(KaTeX는 CDN, 오프라인이면 LaTeX 원문만 보임) | 모듈 1개 + 훅 2곳 | 쉬움(`--no-equation-check`) |
| B. 로컬 서버(`http.server`) | 모든 브라우저에서 저장 | 포트·방화벽·백그라운드 프로세스, GUI와 생명주기 얽힘 | 서버 코드·종료 처리 | 중간 |
| C. HTML 보기 + CLI로 적용 | 단순 | 없음 | 사용자가 명령을 두 번 침 | 쉬움 |

## 결정과 이유
**A.** 사용자 환경이 Windows + Edge/Chrome이고, 설치·실행 복잡도를 늘리지 않으며, 다른 브라우저는 다운로드로 대체된다.
- 파일: `<출력 파일>.equations.html`(출력 옆, 이미지는 base64 내장). 기본 켬(`equation_check`), `--no-equation-check`로 끔.
- 수식 식별: `_format_equation`이 쓰는 블록 그대로 `$$\n<latex> \tag{n}\n$$`를 찾아 바꾼다(번호가 있으면 유일). 이미지만 들어간 식은
  `*Eq. (n)*` 줄 뒤에 블록을 끼워 넣는다. 번호도 LaTeX도 없는 식은 수정 불가로 표시.
- MD는 Windows에서 CRLF로 저장되므로 페이지가 줄 끝을 보존한다.

## 1차 사용 뒤 보강 (2026-10-24)
사용자 확인 결과 두 가지가 필요했다. (1) **연속성**: 페이지에 박힌 OCR 결과만 보여 주어 다시 열면 수정이 안 된 것처럼 보였다 → 페이지가 MD를
연결할 때 현재 텍스트를 읽어 각 식의 `$$` 블록을 **블록 앵커**로 찾고(번호 있는 식 `^eq-3`, 번호 없는 식도 이제 `^eq-u01`을 붙임), 원래 OCR과
다르면 "수정 반영됨"으로 표시한다. 저장도 앵커로 찾은 블록을 바꾸고, 이미지만 있던 식은 앵커 줄 앞에 블록을 끼워 넣는다. 수정 없이 확인한 식은
"검토 완료" 체크를 브라우저 localStorage에 기억한다. (2) **쪽 나누기**: 5·10·20개·전체 선택, 쪽 번호를 `#p=2&n=10`에 남김, 쪽을 옮겨도
저장 전 입력 유지.

## 판정 기준
- paper-01 변환 뒤 페이지에 수식 5개가 쪽·번호·크롭·LaTeX와 함께 뜨고, Edge에서 MD를 연결해 한 식을 고쳐 저장하면 MD의 해당 블록만 바뀌고
  본문 diff는 그 블록뿐이어야 한다(사용자 확인).
- `--no-equation-check`면 파일이 생기지 않고, Word 전용 변환에서는 페이지가 보기 전용으로 열린다.
- pytest: 블록 문자열이 변환기와 일치, JSON 이스케이프(`</script>`), 이미지 없는 식의 폴백 렌더, 기록 수 = 디스플레이 수식 수.

## 되돌릴 조건
- 사용자가 Edge/Chrome이 아닌 브라우저를 주로 써서 다운로드 방식이 번거로우면 B(로컬 서버)를 옵션으로 추가한다.
- 블록 매칭 실패 보고가 나오면(본문 후처리가 `$$` 블록을 바꾸는 경우) `^eq-n` 앵커 기준 매칭으로 바꾼다.
